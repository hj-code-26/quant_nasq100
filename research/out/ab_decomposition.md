## 3. B 의 잔여 미래 정보 (B→C)
B 는 진입 신호만 t-1 로 밀었을 뿐, **청산 판정(손절·만기)과 주문 수량 산정에는
t 일 종가**를 쓴다. 즉 '오늘 종가가 손절선을 깼다'를 보고 '오늘 시가'에 판다.
C 는 판정까지 t-1 종가로 밀어 이 잔여 누수를 제거한다.

- ⓪운영설정: B +159.9% → C +155.7% = **-4.1%p** (잔여 누수 기여분)
- ①손절15+모멘텀0: B +168.2% → C +246.3% = **+78.2%p** (잔여 누수 기여분)
- ④손절25+모멘텀0+회전가드: B +261.4% → C +252.3% = **-9.1%p** (잔여 누수 기여분)

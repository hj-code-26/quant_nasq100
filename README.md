# GAF·VAE Quant — 실시간 반영 주가 예측 퀀트 프로그램

논문 **「촛대 차트의 극좌표 위치 인코딩 이미지에 대한 변이형 오토인코더를 이용한 주가 예측」**
(한양대 조예서, 2022)의 방법론을 핵심 원리로 삼고, **조병호(2021) 「인공지능 머신러닝
기술을 이용한 주식 종목 매수/매도 추천시스템의 분석 및 설계」**(JIIBC 21(4))의 엔진 설계
— 여러 기술적 분석 기법의 결과를 ML 입력으로 결합 — 를 반영했으며, **Goldman Sachs
gs-quant** 의 timeseries 분석 루틴과 **Claude AI 코드 감사 에이전트**를 결합한 프로그램.

## 파이프라인 (논문 [그림 1.1] + 개선)

```
일봉 OHLC (yfinance, 5분 캐시)
  → GAF 인코딩: 시가·고가·저가·종가 극좌표 변환, GADF+GASF 2채널 2×2 타일 (논문 3.2.2 + 개선)
  → Conv VAE 학습(시드 고정) — 검증 구간 제외한 앞부분으로만 학습, 잠재변수 15차원 (논문 3.2.3)
  → + 기술적 지표 12종(인과적 롤링) 결합 → 입력 27차원 (조병호 2021 엔진 설계)
  → 로지스틱 + SVM + 랜덤포레스트 앙상블 → 익일 상승확률 (논문 3.3)
  → Walk-forward 검증 6 walks × 1개월 (논문 3.4.4)
  → 롤링 임계값 보정(직전 walk 로만 결정) + 표본 외 백테스트
  → 특징 구성 A/B 비교(잠재변수 / 지표 / 결합) + McNemar 검정
  → gs-quant: 변동성·RSI·MACD·볼린저·MDD → 예상 주가 1/5/20일 ±σ√h 밴드 (개선)
```

## 실행

```bash
pip install -r requirements.txt
python3 run.py          # http://localhost:8899
```

## 3개 탭 구성

### ① 종목 분석 (핵심 주가·시기 분석)
- 캔들차트 + MA20/60 + 볼린저 + 매수▲/매도▼ 신호 + **예상 주가·밴드**
- 신호 타임라인(최근 120일 상승확률), **다중 시계 예상주가(1/5/20일)**
- **표본 외 백테스트**: Walk-forward 예측만으로 전략 vs 단순보유, 샤프·MDD·승률
- Walk-forward 기간별 성능 표 + 최근 예측 적중 내역
- **특징 구성 A/B 비교**: 같은 walk·같은 VAE·같은 라벨에서 분류기 입력만 바꿔
  ① 잠재변수 15 ② 지표 12 ③ 결합 27 을 비교. 세 구성이 같은 날짜를 예측하므로
  우열은 짝지은 표본 검정(**McNemar**)으로 판정한다 (`backend/ablation.py`)

  > 2026-08-31 측정 — AAPL 126일: 보조지표 30% 블렌딩은 표본 외 정확도를
  > 54.0% -> 51.6% (-2.4%p) 로 **떨어뜨렸다**. `BLEND_W` 는 검증 결과를 보고
  > 조정할 것.
  >
  > 2026-08-31 측정(8종목 × 126일): 평균 정확도 잠재 51.2% / 지표 50.6% / 결합 51.0%,
  > 기준선 52.5%. 결합이 잠재변수를 이긴 종목 3/8(부호검정 p=0.73), 지표를 이긴 종목
  > 4/8(p=1.00), McNemar 유의 종목 0개. **현 구성에서 지표 결합의 이득은 확인되지 않았다.**
- 실시간: 현재가 15초 폴링, 1시간마다 자동 재분석

### ② NASDAQ-100 스캔
- 구성 종목 전체(≈100개)에 고속 파이프라인(2년, 8 epochs, 3 walks) 적용
- **Walk-forward 표본 외 정확도 내림차순 정렬** + 표본 수·95% CI·기준선·p-value 동시 표시
- 진행률/중지/결과 디스크 캐시(`scan_results_v2.json`)
- 행 클릭 → 해당 종목 정밀 분석으로 이동

### ③ AI 코드 감사 (backend/ai_auditor.py)
내부 검증 루틴 → AI 수정 루프:
1. **진단**: 코드 컴파일 / GAF 수학 불변식(GADF 반대칭·대각0·범위, GASF 대칭) /
   데이터셋 무결성(NaN·라벨 균형·최신성) / VAE 사후분포 붕괴 / 분류기·WF 건전성 / gs-quant 지표 /
   **검증 위생(임계값·VAE 구간 분리)** / **특징 인과성(미래 봉이 과거 특징을 바꾸지 않는지)**
2. **실패 시** Claude API(claude-opus-5)에 진단 리포트+소스 전송 → 원인 분석 + 최소 패치(JSON) 수신
3. 화이트리스트 파일만 **백업(.py.bak) 후 패치 적용** → 컴파일 검사 → 모듈 리로드 → **재진단**
4. 개선 없으면 **자동 롤백** (최대 2회 시도)
- AI 수정에는 `ANTHROPIC_API_KEY` 환경변수 필요 (없으면 진단만 수행)

## 논문 대비 조정·개선 사항

| 항목 | 논문 | 본 구현 |
|---|---|---|
| 입력 이미지 | 128×128 RGB GADF | 40×40 GADF+**GASF 2채널** |
| VAE Conv 층 | 5층(128~1024), 4h50m | 3층(32~128), MPS 수십 초 + **학습구간 동일 시 디스크 캐시** |
| 분류기 입력 | 잠재변수 15 | 잠재변수 15 + **기술적 지표 12** (조병호 2021 엔진 설계) |
| 라벨 | C(t+1) ≥ C(t) | **수익률 > 10bp** (왕복 거래비용 미만 변동은 상승으로 세지 않음) |
| 결정 경계값 | 0.5 고정 | **직전 walk 로만 정한 롤링 임계값** + 중립 밴드 |
| 예측 | 익일 이진 분류 | + **1/5/20일 예상 주가**, ±σ√h 밴드, **표본 외 백테스트** |
| Walk-forward | VAE 포함 재학습 | **VAE 는 검증 구간 제외 구간으로만 1회 학습**, 분류기는 walk별 재학습 |
| 성능 보고 | 정확도 단일 수치 | 정확도 + **표본 수·95% CI·다수 클래스 기준선·p-value** |
| 재현성 | — | torch/numpy **시드 고정** |

## 검증 위생 (2026-08 점검 반영)

이전 버전은 표본 외 정확도를 실제보다 약 7%p 높게 표시했다. 원인과 조치:

| 문제 | 조치 |
|---|---|
| 전체 표본 외 예측에서 정확도 최대가 되는 임계값을 고르고 **그 정확도를 다시 표본 외 정확도로 표시** | `backtest.rolling_calibration()` — walk k 의 임계값은 walk 1..k−1 로만 결정, 첫 walk 은 채점 제외. 표본 내 탐색값은 "참고(편향)" 로만 표시 |
| VAE 가 검증 구간을 포함한 전 구간으로 학습 | `pipeline.vae_fit_end()` — 마지막 `walks×21일` 제외하고 학습. 표본 부족 시 `leak_free=False` 로 화면에 경고 |
| 63일 표본 정확도로 100종목 줄세우기(다중비교) | 스캔 표에 표본 수·95% CI·p-value·유의 종목 수 표시. "무작위여도 최고 ~66% 는 나온다" 를 표 아래 명시 |
| 정확도를 0.5 와 비교 | 라벨 불균형을 고려해 **다수 클래스 비율**을 기준선으로 삼아 p-value 계산 |
| 지표는 화면 표시용, 분류기 입력은 잠재변수뿐 | `quant.feature_matrix()` 로 12종 지표를 인과적으로 계산해 잠재변수와 결합 |
| 화면 확률은 보조지표 블렌딩(`p_combined`)인데 검증 수치는 모형 단독 것이었음 | `indicators.p_indicator_asof()` — 구간 통계를 그 시점 이전 데이터로만 계산해 **블렌딩 확률도 표본 외로 채점**. 임계값·백테스트·신호 타임라인도 같은 확률을 쓴다. Walk-forward 표에 「모형 단독」과 「표시 확률(블렌딩)」을 나란히 표시해 블렌딩 효과(%p)를 직접 보여준다 |

AI 감사 탭에 **「검증 위생(누수 방지)」**, **「특징 인과성」** 진단이 추가되어 위 조치가 되돌려지면 실패로 잡힌다.
성능 비교를 수행하는 `ablation.py` 는 컴파일 검사만 받고 AI 자동 패치 대상에서는 제외된다.
